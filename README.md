# שגרירי כללית

מערכת ניהול לתוכנית "שגרירי כללית": עובדי כללית שמפרסמים ברשתות פוסטים בקול שלהם.
המערכת כותבת טיוטות בקול של כל שגריר/ה, והשגריר/ה מאשר/ת או עורך/ת לפני שמשהו עולה.

- **כתובת**: https://ambassador.asaf-bendor-e90.workers.dev (כניסה בסיסמה)
- **שרת**: Cloudflare Worker אחד, בתיקייה `worker/`, עם D1 לנתונים ו-R2 לתמונות ולגיבויים
- **AI**: claude-opus-5-5
- **הוראות שימוש מלאות**: לשונית "הוראות" באתר עצמו

## הזרימה

1. **שאלון למועמד/ת** (`/onboarding`, ציבורי, בעברית, ערבית ורוסית). נשמר אוטומטית במכשיר בזמן המילוי.
2. **טיוטת פרופיל קול** נכתבת מהתשובות (בלי המייל). אדם קורא, מתקן ושומר כשגריר/ה.
3. **יצירת פוסט**: שלוש גרסאות, כל אחת עם ציון דמיון לקול. אפשר לכתוב מנושא, מלוח הנושאים
   או מסיפור שהשגריר/ה שלח/ה בקישור האישי שלו/ה (`/story/<token>`).
4. **בדיקת בטיחות** לפני שליחה: פרטים מזהים של מטופלים, טענות רפואיות, נושאים רגישים, גבולות
   מהשאלון ופרטים בלי מקור. רק מסמנת.
5. **אישור** בקישור אישי (`/review/<token>`): השגריר/ה עורך/ת, בוחר/ת גרסה ומאשר/ת. הקישור פג אחרי 14 יום
   כל עוד לא אושר.
6. **פרסום** על ידי השגריר/ה בלבד: העתקה ופתיחת לינקדאין, X, פייסבוק או אינסטגרם. קישור מעקב לתגובה
   הראשונה, ושדות לקישור לפוסט, צפיות ותגובות.
7. **למידה**: ההבדל בין הטיוטה לנוסח שאושר הופך להצעת כללי כתיבה, ונכנס לפרופיל רק בלחיצה.

עוד במערכת: לוח פרסומים עם אזהרה על אותו נושא באותו יום, לוח נושאים, מאגר תמונות מאושרות,
הצעת פרופיל ללינקדאין וכללים לשגריר/ה, סיכום שבועי לשליחה בוואטסאפ, דוח חודשי להנהלה עם שיעור
העריכה לאורך זמן ושווי משוער, יומן פעילות, וגיבוי יומי אוטומטי.

## הרצה ופריסה

```bash
cd worker
npm install
npx wrangler dev        # מקומי
npx wrangler deploy     # לאתר החי
```

push ל-`main` לא מפרסם שום דבר לבד. פרטים מלאים, סודות, מבנה הנתונים ושאילתות קריאה: `CLAUDE.md`.

## היסטוריה

עד 10 בנובמבר 2026 האפליקציה רצה כ-Next.js על Railway (התיקייה `dashboard/`, נשמרה לתיעוד בלבד).
הנתונים הועברו ל-D1 ול-R2, ונבדקו בספירה לפני ואחרי: 4 שגרירים, 2 מועמדים ו-5 פוסטים.
הפרויקט ב-Railway נמחק אחרי שהגיבוי האחרון ממנו הושווה לגיבוי של המעבר ונמצא זהה.
